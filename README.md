# Physics-Informed Neural Network for Optimal Power Flow

This repository contains my learning notes and experiments on applying Physics-Informed Neural Networks (PINNs) to the Optimal Power Flow (OPF) problem.

## Objective

The goal of this repository is to understand how neural networks can be trained with physical constraints from power systems, instead of relying only on supervised labels.
